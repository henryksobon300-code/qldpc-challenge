I compared @hirobumii's CSS lifted-product code from [PR #3867](https://github.com/unitaryfoundation/qldpc-challenge/pull/3867) with a distinct lifted-product construction. Both codes have parameters [[980,398,6]] and maximum check weight 8. The comparison uses independent depolarizing noise, perfect syndrome measurement and optimal Pauli recovery. The metric is the coefficient of the cube of the physical error probability in the logical failure probability as that probability approaches zero.

| Quantity | Code from PR #3867 | New instance |
| --- | ---: | ---: |
| Weight-six nontrivial Pauli operators, ignoring phase | 20027 | 19110 |
| Unavoidable weight-three failures | 171878 | 165228 |
| Leading logical failure coefficient | 171878/27 | 165228/27 |

The relative coefficient reduction is exactly 475/12277, about 3.869%.

## Construction and counting

The group is the semidirect product of C7 and C14 with inversion action. With coordinates encoded as i + 7j, the new left generators are (7, 22, 40) and right generators are (7, 23, 38). The construction uses nine variable-variable blocks and one check-check block, each with 98 coordinates. Both X and Z check matrices have rank 291.

For each matrix, the exact comparison classifies zero-syndrome supports through weight six. Every minimum support is a six-cycle in a variable-variable block or uses one check-check coordinate with a shortest path in each variable-variable block. The latter family contributes 35 operators to the code from PR #3867 and zero to the new instance. Both sectors have distance six. The unequal weight-six Pauli counts establish inequivalence under qubit permutation and single-qubit Clifford operations.

At weight three, any same-syndrome ambiguity arises from complementary halves of a weight-six logical. A syndrome with r equally likely logical alternatives contributes r - 1 unavoidable failures. The replay counts each such syndrome class and includes 16768976 exhaustive three-edge checks as a cross-check. The leading coefficient measures the small-noise asymptotic under the stated model.
